# PROYECTO FINAL
## Sistema inteligente de planificación, optimización y toma de decisiones adversarias

### 1. Descripción del proyecto

Este proyecto consiste en desarrollar un sistema inteligente utilizando Python para resolver un problema de planificación de entregas.

El sistema utiliza diferentes algoritmos para encontrar rutas, mejorar recorridos, analizar decisiones y competir por recursos.

### 2. Archivos del proyecto

- escenario.py: Crea el mapa de entregas de 12 x 12.
- busqueda.py: Implementa los algoritmos Greedy y A*.
- hill_climbing.py: Busca mejorar el orden de las entregas.
- recocido_genetico.py: Implementa recocido simulado y algoritmo genético.
- teoria_juegos.py: Analiza las decisiones de dos empresas mediante una matriz de recompensas.
- minimax.py: Implementa Minimax y poda alfa-beta.
- principal.py: Ejecuta los programas y guarda los resultados.
- resultados.csv: Almacena los resultados obtenidos de los algoritmos.

### 3. Requisitos

Para ejecutar el proyecto se necesita:

- Tener Python instalado.
- Contar con los archivos del proyecto en una misma carpeta.
- Utilizar un editor de código como Visual Studio Code o IDLE.

### 4. Instrucciones de ejecución

1. Abrir la carpeta del proyecto.
2. Verificar que todos los archivos de Python estén guardados en la misma ubicación.
3. Abrir una terminal.
4. Ejecutar el siguiente comando:

5. Esperar a que terminen las ejecuciones.
6. Revisar los resultados que aparecen en pantalla.
7. Abrir el archivo resultados.csv para consultar los datos guardados.

### 5. Resultados

El sistema muestra los resultados de los diferentes algoritmos, incluyendo rutas, costos, puntos obtenidos y nodos visitados.

Los resultados se guardan en un archivo CSV para facilitar su revisión y comparación.

### 6. Conclusión

El proyecto permite conocer y aplicar diferentes algoritmos de inteligencia artificial para resolver problemas de planificación y toma de decisiones.

Mediante los resultados se pueden comparar los métodos utilizados y observar cómo cada algoritmo busca una solución al problema planteado.
